## How to run

```bash
python -m venv venv

# Mac/Linux:
source venv/bin/activate
# Windows:
venv\Scripts\activate

pip install -r requirements.txt

python train.py    # trains the model, saves model.pkl and static/feature_importance.png
python app.py       # starts the Flask server
```

Open **http://localhost:5000** in your browser. Fill in the form and click Predict — you'll see the risk level, a probability breakdown, and the feature-importance chart.
